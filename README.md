# AI Resume Job Matcher

AI-powered Resume Job Matcher that analyzes resumes and job descriptions to find relevant job opportunities. The project uses Python, FastAPI, NLP, semantic matching, RAG, and embeddings to extract important information from resumes and compare candidate skills with job requirements.

## Technologies Used

* Python
* FastAPI
* NLP
* RAG
* Embeddings
* Semantic Matching
* PDF Processing

## Key Features

* Resume PDF upload and processing
* Resume text extraction
* Job description analysis
* Skill matching
* Semantic similarity-based recommendations
* AI-powered resume analysis

## Purpose

The project helps candidates understand how well their resume matches a job description and identify relevant opportunities based on their skills and experience.
